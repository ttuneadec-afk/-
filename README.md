# Каркас приложения: управление каналообразованием

Стартовый проект на Avalonia UI (C#, .NET 8) для ВКР.
Собирается под Windows; в перспективе — под Android тем же кодом.

## Что уже сделано
- Главный экран-меню: «Запустить контроль», «Каналы», «Настройки», «О системе», «Выход».
- Переключение экранов через ContentControl (Host) + кнопка «Назад».
- Экран настроек с периодом опроса (ComboBox) и переключателем журнала.
- GitHub Actions workflow: при каждом push собирает Windows-версию (artifact windows-app).

## Как работать с телефона
1. Создай репозиторий на GitHub, загрузи туда содержимое папки ChannelApp + workflow.
2. Открой репозиторий в браузере → Code → Codespaces (работает в мобильном Chrome).
3. Редактируй код, коммить: Actions соберёт exe, скачай artifact и запусти на любом ПК.
4. Для теста на телефоне позже добавим job сборки Android APK — тот же код.

## Локальная сборка (на компьютере)
```
dotnet publish ChannelApp -c Release -r win-x64 --self-contained false -o out
```
